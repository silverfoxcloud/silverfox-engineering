# Silver Fox Engineering — Design Platform Adoption Business Model

## Role in the ecosystem

Silver Fox Engineering is the first real consumer and reference implementation of the centralized Silver Fox public-web platform.

It is not the design-system source of truth. The source of truth is:
`silverfoxcloud/silverfox-web-design-system`.

## Why this pilot exists

The pilot must prove that:
- shared design/runtime capabilities can be versioned centrally;
- a real production website can consume them without copying source;
- Engineering keeps its technical/editorial identity;
- future design updates can flow through package upgrades;
- reusable improvements discovered here can move upstream.

## Value

### For Engineering
Less local design infrastructure to maintain.

### For Silver Fox main
A proven corporate-ready platform can be built from the same primitives.

### For Fastreserve
Approved mature patterns can migrate without destroying product identity.

### For future sites
New sites begin as consumers instead of inventing local headers, footers, token systems, RTL rules and QA stacks.

## Non-goal

This phase does not make all Silver Fox sites visually identical.

The shared platform governs reusable behavior and design grammar.
Content, product visuals, information architecture and page storytelling remain consumer/profile responsibilities.
